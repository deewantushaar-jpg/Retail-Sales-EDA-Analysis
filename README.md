# Retail Sales Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales performance, customer behavior, product category trends, and sales patterns over time in order to support better business decisions.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

* Data loading and understanding
* Missing value and duplicate record checks
* Date column preparation for time-series analysis
* Descriptive statistics
* Sales analysis by product category
* Quantity analysis by product category
* Customer analysis by gender and age
* Sales trend analysis over time
* Correlation heatmap
* Business insights and recommendations

## Key Insights

* The dataset contains 1,000 retail sales transactions.
* The dataset had no missing values and no duplicate records.
* Total sales amounted to 456,000.
* Electronics generated the highest revenue, followed closely by Clothing.
* Clothing recorded the highest quantity sold.
* Female customers contributed slightly higher total sales than male customers.

## Recommendations

* Focus inventory and product planning on Electronics and Clothing.
* Monitor high-demand categories to reduce the risk of stock shortages.
* Use customer analysis to support more targeted marketing decisions.
* Track sales trends over time to identify weaker periods for promotions and offers.

## Conclusion

This project demonstrates how exploratory data analysis can be used to identify useful business insights from retail sales data. Through data cleaning, statistical analysis, time-series analysis, and visualizations, the project supports better decisions in product performance, inventory planning, and customer targeting.
